# Module dependencies

`reverso-text-buffer` depends on Rust standard library only. `reverso-editor-engine` depends on `reverso-text-buffer` and standard library. Android `app` uses Activity Compose, Compose UI/Material 3, AndroidX DocumentFile, Kotlin coroutines supplied by the Compose runtime, Android Keystore APIs, and JUnit for local tests. No additional crypto or HTTP library is added: AES-GCM comes from the Android/JCA platform and HTTPS uses `HttpsURLConnection`. The Android module still does not depend on Rust/JNI. There are no module cycles. Keep storage/provider adapters separate from reusable editor UI.
