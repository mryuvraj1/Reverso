# Security design

The app requests Internet access for release checks and does not request broad storage access. User files are opened and saved only through Android’s document picker. The Rust crates forbid unsafe code and use no external crates. The app does not execute file contents. Save/open errors are shown in the editor status; file-size limits are not implemented. The app makes an unauthenticated HTTPS request to the public GitHub Releases API at startup and opens only an HTTPS `github.com` release URL from the response. It does not fetch executable APKs or install updates. Android still controls app installation. There is no terminal, cloud execution, or extension loading code. Future terminal/cloud work must define isolation and authentication before command execution is exposed.
