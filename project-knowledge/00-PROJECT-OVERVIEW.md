# Reverso project overview

Reverso targets an Android-first, mobile developer environment. This checkout is an early Phase 1 foundation, not the full product. It contains a Rust text editing core and a Kotlin/Jetpack Compose IDE shell. The app supports user-granted SAF workspaces, exact-extension file creation and Save As, nested creation, recent workspace restore, provider-backed file operations, basic syntax-colored editing, and a professional Reverso-branded responsive layout with toggleable/resizable panels and opt-in direct AI provider chat. The Android Updates destination is directly accessible from the phone activity rail, welcome screen, and Settings shortcut. It checks the official GitHub Releases API on launch and periodically, caches releases, supports Stable/Stable + Beta settings and deduplicated notifications, and offers a SHA-256-aware APK download with progress and Android’s user-confirmed installer handoff.

The phone UI uses touch-sized activity navigation and a focused content destination; wide layouts show a rail, Explorer/Search sidebar and editor. The Android editor is still Compose-backed and does not call Rust through JNI. The UI exposes terminal, Git, debugger, extensions, and diagnostics areas, but explains that their real backends are not connected. No commands are run and no extension is installed by those panels.

The update manager is documented in [17-UPDATE-SYSTEM.md](17-UPDATE-SYSTEM.md). Unit tests cover deterministic selection and helper behavior; live API, device notification, APK download and package-install/upgrade behavior still require emulator/device verification. AI supports OpenAI-compatible chat providers and Anthropic Messages. Per-provider API keys are encrypted with Android Keystore; file context is opt-in and chat is held in memory.
