# Contributing

1. Open an issue describing the problem or proposed change.
2. Keep platform UI and editor behavior separated; explain any dependency additions.
3. Update project knowledge and the file index alongside meaningful code changes.
4. Run Rust formatting/tests/clippy and Android lint/build when the required toolchains are available.
5. Submit a pull request with behavior, verification, and limitations stated plainly.

Do not commit credentials, local SDK configuration, build outputs, or generated binaries.
